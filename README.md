# QuickNotes

## Description

QuickNotes is a single-page note-taking web application built with HTML, CSS, and JavaScript. It allows users to quickly capture thoughts, tasks, and ideas, categorize them, and search through them. The app uses browser localStorage so that notes are not deleted when the user closes the browser tab.

## Features

- **Add Notes:** Quickly add new notes with a text input and a category dropdown (Personal, Work, Study).
- **Categorization:** Notes are visually organized with distinct color-coded left borders for each category.
- **Live Search:** Instantly filter your notes as you type in the search bar.
- **Delete Notes:** Remove unwanted notes with a single click.
- **Data Persistence:** All notes are automatically saved to the browser's `localStorage`, so they survive page refreshes and browser restarts.
- **Input Validation:** The app prevents empty notes and notes over 200 characters, displaying clear error messages.
- **Responsive Design:** The layout adapts smoothly to mobile devices.

## How to Run Locally

1. Clone this repository to your local machine.
2. Open the project folder in your code editor (like VS Code).
3. Right-click on `index.html` and select **"Open with Live Server"**
4. Start adding notes!

## What I Learned

I developed a deeper understanding of web development and was amazed by how the app came together. Each language we used had a completely different purpose and worked together to make the final product:

1. **HTML (Structure):** I learned that HTML is the skeleton of the page. It provides the semantic structure and organizes all the content, forms, and lists.
2. **CSS (Styling):** I learned that CSS is what makes the app beautiful and responsive. It controls the layout, colors, card designs, and makes sure the app looks good on mobile phones.
3. **JavaScript (Functionality):** I learned that JavaScript is the brain of the app. It handles all the user interactions like adding, deleting, searching, and saving notes to the browser's localStorage so they don't disappear.

It was incredible to see how these three separate languages came together to build a fully working, interactive application from scratch!
